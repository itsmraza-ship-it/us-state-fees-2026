# Changelog

All notable changes to the fee dataset. Format follows [Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] — 2026-10-13

### Added
- Initial dataset: LLC formation filing fees for 6 verified states — Wyoming ($102), New Mexico ($50), Delaware ($90), Missouri ($50), Texas ($308), Florida ($125).
- `fees.csv` and `fees.json` with `state`, `filing_fee_usd`, `verified_source_note`, and disclaimer fields.
- README with usage examples (Python, JavaScript) and contribution rules.
- All fees cross-checked against published state filing offices via epicsdeals.com/state-fee (Oct 2026).
